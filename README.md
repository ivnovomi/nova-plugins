# NOVA Plugins

La tienda de plugins de **NOVA TV**: canales, filas para "Para ti", búsquedas, fondos de salvapantallas y apps para la tele, creados por la comunidad con [`@novatv/sdk`](https://www.npmjs.com/package/@novatv/sdk).

> **Próximamente.** El SDK y el proceso de envío están en desarrollo.

## Cómo funcionará

1. Escribes tu plugin en TypeScript con `@novatv/sdk`.
2. Envías **el código fuente** a este repositorio con un pull request.
3. La integración continua lo compila, pasa las comprobaciones automáticas y el equipo de NOVA lo revisa.
4. Si se aprueba, se firma y llega a todas las NOVA TV a través de la tienda.

Solo se publican plugins revisados. Las normas de contenido (resumen): nada de piratería ni de saltarse DRM, sin apuestas, sin contenido adulto, sin anuncios insertados y sin seguimiento.
